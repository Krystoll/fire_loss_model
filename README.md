# 🔥 Модели и методы определения ущерба от пожаров

Практическая работа №1 по дисциплине **«Теория информационных процессов и систем»**.

Интерактивный веб-сервис для моделирования ущерба от пожаров в зданиях, лесных массивах и на промышленных объектах на основе системно-динамического подхода.

---

## 📋 Описание

Проект представляет собой **математическую модель системной динамики**, включающую **14 ключевых показателей потерь** от пожаров, описываемых системой нелинейных дифференциальных уравнений первого порядка.

Модель реализована в виде **веб-приложения на Python** с использованием фреймворка **Flask**. Приложение позволяет:

- задавать начальные значения показателей потерь;
- настраивать коэффициенты нормализации;
- изменять параметры вспомогательных функций и возмущений;
- визуализировать динамику всех 14 переменных во времени (линейные графики);
- строить полярные (радарные) диаграммы для сравнения текущих потерь с экологическими нормативами.

## 🧮 Математическая модель

### Моделируемые переменные

Модель включает **14 переменных** \(X_1(t), \dots, X_{14}(t)\):

| № | Переменная | Описание |
|---|------------|----------|
| \(X_1\) | Потери от гибели и травм людей | Медицинские расходы, компенсации |
| \(X_2\) | Потери от уничтожения зданий | Стоимость восстановления |
| \(X_3\) | Потери от уничтожения имущества | Оборудование, товары |
| \(X_4\) | Потери от повреждения лесных массивов | Ущерб лесному хозяйству |
| \(X_5\) | Потери от загрязнения атмосферы | Продукты горения |
| \(X_6\) | Затраты на тушение пожара | Техника, огнетушащие средства |
| \(X_7\) | Потери от остановки производства | Упущенная выгода |
| \(X_8\) | Потери от нарушения инфраструктуры | Транспорт, энергетика |
| \(X_9\) | Социальные потери | Паника, стресс |
| \(X_{10}\) | Экологические потери | Загрязнение почв, водоёмов |
| \(X_{11}\) | Потери туристической привлекательности | Отток туристов |
| \(X_{12}\) | Страховые выплаты | Расходы страховых компаний |
| \(X_{13}\) | Потери от вторичных пожаров | Взрывы, обрушения |
| \(X_{14}\) | Долгосрочные экономические последствия | Инвестиции, безработица |

### Система дифференциальных уравнений

Общий вид уравнения для \(i\)-й переменной:

\[
\frac{dX_i}{dt} = \frac{1}{K_i}\left(\sum_{j=1}^{14} f_{ij}(X_j) + \sum_{k=1}^{14} g_{ik}(\zeta_k)\right)
\]

где:
- \(K_i\) — нормировочные множители;
- \(f_{ij}(\cdot)\) — вспомогательные полиномиальные функции 3-й степени;
- \(g_{ik}(\cdot)\) — функции возмущений;
- \(\zeta_k\) — k-е возмущающее воздействие.

### Возмущения

Всего **14 возмущений**: рост числа источников возгорания, изменение климата, ужесточение экологических норм, санкционные ограничения, рост стоимости строительства, увеличение плотности застройки, износ пожарной техники, сокращение финансирования, рост тарифов на страхование, урбанизация лесных территорий, недостаток кадров, устаревание нормативов, аномальные погодные явления, неопределённость экономики.

### Целевая функция

\[
F = \sum_{i=1}^{14} w_i \cdot X_i(t) \to \min
\]
